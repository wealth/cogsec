Auto-runs on X, Bluesky, Reddit, Threads, Hacker News, 4chan and 2ch. Any other page: click Analyze.
Local: LM Studio → Developer → Start server, CORS on (or lms server start --cors). Hosted: pick a preset, paste a key, type a model id. Jev (TypeSafe) answers the taxonomy natively and needs a key from console.typesafe.ai. Saving a hosted URL asks for permission to contact that site.
Vision models only (e.g. Qwen 3.5). Up to 2 images per post, downscaled to 512 px. Adds about a second per image. Images go wherever your endpoint is: keep a local model if that matters.
